# ゲート定義(M3)

ゲートレベル エミュレータ(`emu/src/gates.rs`)の仕様。基本ゲートは案 A(ADR 0006)。

## 1. 信号と電圧

| 値 | 電圧(目安) |
|---|---|
| `-` | -5V |
| `0` | 0V |
| `+` | +5V |

2 進比較用の回路では `-` を 2 進の 0、`+` を 2 進の 1 として扱う(同じ電源・同じ素子で比べるため)。

定数 `-` / `0` / `+` は電源レール(-5V / GND / +5V)なので部品コスト 0 とする。

## 2. 基本ゲート(プリミティブ)

### 2.1 真理値表

| ゲート | 入力 | `-` | `0` | `+` | 種別 |
|---|---|---|---|---|---|
| STI | 1 | + | 0 | - | 能動(トランジスタ) |
| NTI | 1 | + | - | - | 能動 |
| PTI | 1 | + | + | - | 能動 |
| BNOT | 1 | + | (未定義) | - | 能動。2 進比較用のインバータ。入力は `-`/`+` のみ |
| ENC(p, n) | 2 | 下表 | | | 能動(実験的、ADR 0007) |
| MIN(n) | n | 入力の最小値 | | | 受動(ダイオード) |
| MAX(n) | n | 入力の最大値 | | | 受動 |

- NTI / PTI の出力は `-` か `+` だけ(0V を出さない)。**2 値の信号にかけると 2 進インバータとして働く**
  (NTI(+) = -, NTI(-) = +)。
- 0V を自分で作る(どちらのスイッチも OFF にする)必要があるのは STI だけ。
- MIN / MAX はダイオード n 本と抵抗 1 本。トランジスタを使わない代わりに、レベルを再生しない。

**ENC(p, n)**: 2 値の信号 2 本から 3 値を能動的に出す出力段。STI と同じ 2 スイッチ構成で、
p が上のスイッチ(+5V へ)、n が下のスイッチ(-5V へ)を入れる。

| p | n | 出力 |
|---|---|---|
| - | - | 0(どちらも OFF、抵抗で 0V) |
| + | - | + |
| - | + | - |
| + | + | **禁止**(±5V の短絡)。シミュレータは検出して停止する |

入力は 2 値(`-`/`+`)のみ。

### 2.2 部品コスト(暫定)

**M4 の SPICE 検証で見直す仮の値**。コード上は `Prim::cost()` の 1 か所で定義する。

| ゲート | トランジスタ | ダイオード | 抵抗 | 想定回路 |
|---|---|---|---|---|
| STI | 2 | 0 | 3 | NPN + PNP、ベース抵抗 2、0V に引く抵抗 1 |
| NTI | 1 | 1 | 2 | しきい値をずらすダイオード 1 + トランジスタ 1 |
| PTI | 1 | 1 | 2 | NTI の極性違い |
| BNOT | 1 | 0 | 2 | 普通の 2 進インバータ |
| MIN(n) / MAX(n) | 0 | n | 1 | ダイオードゲート |
| ENC | 2 | 0 | 3 | STI の出力段と同じ(入力を 2 本に分けたもの) |

## 3. 複合ゲート

すべて基本ゲートの組み合わせで定義する(コストは基本ゲートの合計)。

### 3.1 デコーダ DEC(x)

x を 3 本の 2 値信号に分ける。トランジスタ 4。

```
isN  = NTI(x)            x = - なら +
notN = NTI(isN)          x ≠ - なら +
notP = PTI(x)            x ≠ + なら +
isP  = PTI(notP)         x = + なら +
isZ  = MIN(notN, notP)   x = 0 なら +
```

### 3.2 SUM(a, b) — mod 3 の和(半加算器の和)

積和形。各項は 2 値信号の MIN で、結果が 0 になる行には定数 0 を混ぜる。ちょうど 1 行だけが
`+` になるので、MAX でまとめると答えになる。

```
SUM = MAX( MIN(aN, bN), MIN(aZ, bP), MIN(aP, bZ),          ← 結果 +
           MIN(aN, bP, 0), MIN(aZ, bZ, 0), MIN(aP, bN, 0) )  ← 結果 0
```

(結果 - の行は、どの項も `-` になることで表される)

### 3.2b SUM_ENC(a, b) — 出力段付きの SUM

結果が + になる行の OR を p、- になる行の OR を n として ENC で出す。0 の行は「どちらも OFF」で
表されるので項が要らない。出力はレベル再生済み。

```
P = MAX( MIN(aN, bN), MIN(aZ, bP), MIN(aP, bZ) )
N = MAX( MIN(aN, bZ), MIN(aZ, bN), MIN(aP, bP) )
SUM_ENC = ENC(P, N)
```

さらに Z = MAX( MIN(aN, bP), MIN(aZ, bZ), MIN(aP, bN) ) を作ると、(N, Z, P) は和の 2 値 3 本
(DEC(和) と同じ値)になる。

### 3.3 CONS(a, b) — 一致(半加算器のキャリー)

a = b なら a、そうでなければ 0。**ダイオードだけ**で作れる。

```
CONS = MAX( MIN(a, b), MIN(MAX(a, b), 0) )
```

### 3.4 ANY(a, b) — 0 でない方を通す

一方が 0 なら他方、同符号ならその値、異符号なら 0。MIN/MAX と定数だけでは作れない
(総当たりで確認済み)。M = MAX(a, b)、m = MIN(a, b) として:

```
ANY = MAX( MIN(M, notN(m)),  MIN(isP(M), isN(m), 0) )
```

notN(m) = NTI(NTI(m))、isP(M) = PTI(PTI(M))、isN(m) = NTI(m)。トランジスタ 4。

ENC 版(出力はレベル再生済み、トランジスタ 6):

```
ANY_ENC = ENC( MIN(isP(M), notN(m)),  MIN(isN(m), notP(M)) )
```

### 3.5 BUF(x) — レベル再生

ダイオードを何段も通った信号を整え直す。

- 3 値: `BUF = STI(STI(x))`(トランジスタ 4)
- 2 値: `BUF = BNOT(BNOT(x))`(トランジスタ 2)

## 4. 加算器

### 4.1 3 進 全加算器

```
s1 = SUM(a, b)      c1 = CONS(a, b)
s  = SUM(s1, cin)   c2 = CONS(s1, cin)
cout = ANY(c1, c2)
```

`a + b + cin = s + 3·cout` を 27 通りすべてで満たす(c1 + c2 が常に cout に等しい)。

オプション(組み合わせ可):

| オプション | 内容 |
|---|---|
| `restore` | s1、s、cout に BUF を入れる。入れないと、キャリーがダイオードを通り続け、受動段数が段数に比例して伸びる |
| `reuse_s1` | 改善候補 1。1 段目の SUM の内部で得た s1 の 2 値 3 本(3.2b の N, Z, P)を 2 段目の SUM にそのまま渡し、DEC(s1) を省く。s1 の 3 値は CONS のために別に作る |
| `enc` | 改善候補 3。SUM と ANY を ENC 版にする。出力が能動的に駆動されるので、`restore` の BUF は入れない |

### 4.2 2 進 全加算器(比較用)

入力 a, b, cin と、その反転 na, nb, nc(BNOT)を使う積和形。

```
s    = OR( AND(a,nb,nc), AND(na,b,nc), AND(na,nb,cin), AND(a,b,cin) )
cout = OR( AND(a,b), AND(a,cin), AND(b,cin) )
```

AND = MIN、OR = MAX(同じダイオードゲート)。`restore` で s、cout に BUF を入れる。

### 4.3 N 桁リップルキャリー加算器

全加算器を下位から連鎖させる。入力 `a0..a(N-1), b0..b(N-1), cin`、出力 `s0..s(N-1), cout`。

比較の基準: 3 進 9 トリット(±9841)と、それを覆う 2 進 15 ビット(0〜32767 / 符号付き ±16383)。

## 5. 評価指標

| 指標 | 定義 |
|---|---|
| 部品数 | トランジスタ / ダイオード / 抵抗の合計(2.2 の表による) |
| 受動段数 | 能動ゲートを挟まずに連続して通る MIN/MAX の最大段数。入力・定数・能動ゲート出力を 0 とし、MIN/MAX で +1。レベル劣化の目安 |
| ゲート段数 | 入力から出力までの最長経路上のゲート数(速さの目安) |
| 能動段数 | 最長経路上の能動ゲート数 |
| 2 値信号線の割合 | ゲート出力の配線のうち、シミュレーション中に一度も 0 をとらなかったもの(0V が現れない配線)の割合。全網羅できる回路は全網羅、それ以外はサンプル入力で測る |
| 3 値配線の数 | ゲート出力の配線のうち、-, 0, + のすべてをとったものの数。「- か 0 だけ」の配線は 2 値信号線にも 3 値配線にも入らないので、3 進らしさはこちらで見る |

受動段数の許容値は M4(SPICE)で決める。

「素直」「s1再利用」は受動段数がキャリーの連鎖で伸び続けるので、実機では使えない(比較用)。
実用候補は受動段数が一定の「再生あり」系と「ENC」系。

★標準構成は ENC(ADR 0007, 0008)。

### 読み取れること

- **ENC(改善候補 3)は全面的に効く**: 再生ありと比べ、部品 -11%(1962 → 1755)、ゲート段数 -20%
  (97 → 78)、受動段数 6 → 4。3 値配線は 9 本でほぼ変わらない(3 進らしさを保つ)
- **s1 再利用(改善候補 1)の効果は小さい**: トランジスタは 1 桁 -4 だが、s1 の「0 の行」の項を
  作るためダイオードが増え、部品計は 1〜3% 減にとどまる。キャリーの経路に触れないのでゲート段数は
  減らず(再生ありでは +2)、DEC のレベル再生がなくなる分、受動段数は ENC 版で 4 → 5 に伸びる
- 2 値信号線の割合は ENC で上がって見えるが、元の SUM の「- か 0 だけをとる配線」が消えたため。
  3 値配線の数で見ると変わらない
- 最良の s1再利用+ENC でも、2 進 15 ビット(再生あり)に対し部品数 約 2.1 倍、ゲート段数 約 1.3 倍
- トランジスタの大半は依然 DEC にある。差を詰めるには、デコードせずに SUM / ANY を作る方法が要る
