# 命令セット仕様(ISA v0)

独自の最小 ISA。アキュムレータ方式・1 アドレス方式(Setun と同じ考え方)。
命令は後から追加できるよう、オペコード空間の大半を予約にしてある。

数表現は `balanced-ternary.md` に従う。

## 1. 構成

| 項目 | 仕様 |
|---|---|
| 語長 | 9 トリット(命令・データ共通) |
| メモリ | 729 語。アドレスは **平衡 6 トリット -364〜+364** |
| 命令とデータ | 同じメモリに置く(ノイマン型) |
| ACC | アキュムレータ 9 トリット |
| C | キャリーフラグ 1 トリット(-1 / 0 / +1) |
| PC | プログラムカウンタ 6 トリット。リセット時 0。+1 で進み、+364 の次は -364(ラップ) |

リセット時: ACC = 0、C = 0、PC = 0、メモリはロードしたプログラム以外 0。

## 2. 命令語の形式

```
 t8 t7 t6 | t5 t4 t3 t2 t1 t0
  opcode  |      operand
 (3 trit) |     (6 trit)
```

- opcode: 上位 3 トリット(-13〜+13、27 種)
- operand: 下位 6 トリット(-364〜+364)。アドレスまたは即値
- 命令語の整数値は `opcode × 729 + operand`(平衡三進では上位/下位の分解が一意)

## 3. 命令一覧

| op | 名前 | 動作 | C |
|---|---|---|---|
| 0 | HALT | 停止 | 不変 |
| +1 | LDA a | ACC ← mem[a] | 不変 |
| +2 | STA a | mem[a] ← ACC | 不変 |
| +3 | LDI n | ACC ← n(即値 -364〜+364) | 不変 |
| +4 | ADD a | ACC ← ACC + mem[a](ラップ) | ← キャリー出力 |
| +5 | NEG | ACC ← -ACC(operand は無視、0 を推奨) | 不変 |
| +6 | JMP a | PC ← a | 不変 |
| +7 | BR3 a | PC ← a + sign(ACC) | 不変 |
| +8 | OUT | ACC を出力装置へ書き出す(operand 無視) | 不変 |
| その他 | (予約) | 実行すると不正命令エラーで停止 | |

- `MOV`(要件定義の初期案)は、メモリとの転送 LDA / STA と即値ロード LDI に分けた。
- 減算は `NEG` + `ADD` で行う。
- `HALT` を 0 にしたので、0 で埋まった領域に飛び込むと停止する(暴走防止)。
- 命令は PC を +1 してから実行する(JMP / BR3 は上書き)。

### 3.1 BR3(3 分岐)

`BR3 a` は ACC の符号で飛び先が変わる。

| ACC | 飛び先 |
|---|---|
| 負 | a - 1 |
| 0 | a |
| 正 | a + 1 |

典型的には a-1, a, a+1 に JMP を並べた「分岐表」を置く:

```
        BR3  table
        JMP  on_neg     ; table-1
table:  JMP  on_zero
        JMP  on_pos     ; table+1
```

飛び先がアドレス範囲外になる場合はラップする(-364 - 1 → +364)。

### 3.2 キャリーフラグ

`ADD` は `ACC + mem[a] = 結果 + C × 3^9` となるよう C を設定する。
C ≠ 0 がオーバーフロー。現状 C を読む命令はない(将来 ADC / BRC 等を追加する余地)。

## 4. 実機 ALU との関係(M6 向け)

ADD は「ACC と mem[a] の 2 入力 → 9 トリット結果 + キャリー」の純粋な関数として
エミュレータから差し替え可能にしておく。実機 ALU が 3〜6 トリットの間は、マイコン側で
下位から分割してキャリーを連鎖させる(多倍長加算)。

## 5. アセンブリ言語(.t3asm)

```
; コメント
label:  OP  operand     ; operand は 10 進数、0t+0-(三進リテラル)、ラベル、ラベル±数
        .org 100        ; 以降の配置アドレスを変更
        .word 15        ; データ語(9 トリット範囲の値またはラベル)
```

- ニーモニックは大文字小文字を区別しない
- operand を省略できる命令: HALT, NEG, OUT(0 になる)
- 三進リテラル `0t` に続けて `+ 0 -`(`T` / `1` も可)を書く。例: `0t+0-` = 8
