# ADR 0003: ISA v0(アキュムレータ・1 アドレス・9 トリット)

- 状態: 採用(M2 時点)
- 日付: 2026-11-08

## 決定(ユーザー確認済み)

- アキュムレータ方式、1 アドレス方式
- 命令・データとも 9 トリット。opcode 3 + operand 6
- ADD のオーバーフローはラップし、キャリーを 1 トリットのフラグ C に残す
- Setun 互換ではなく独自の最小 ISA(Setun 互換は M7 で別途)

## 補足の判断(Claude による、変更可)

- **アドレスを平衡 6 トリット(-364〜+364)にした**: 命令語の下位 6 トリットをそのまま使え、
  変換が要らない。負のアドレスはデータ置き場として自然に使える。
- **MOV を LDA / STA / LDI に分割**: アキュムレータ方式では「コピー」が転送方向で別命令になる。
- **HALT = 0**: 未初期化メモリ(0)に飛んだら止まる。
- **BR3 a は a + sign(ACC) に飛ぶ**: 1 アドレス形式で 3 分岐を表すため。分岐表を置く形は
  平衡三進の対称性(-1 / 0 / +1)がそのまま現れる。
- **OUT を追加**: 要件定義の初期案にはないが、カウントダウン等のサンプルの結果確認と、
  実機フェーズの自動照合(出力列の比較)に使うため。
