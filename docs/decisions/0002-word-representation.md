# ADR 0002: ワードの内部表現と表記

- 状態: 採用(M1 時点)
- 日付: 2026-11-07

## 決定

- トリットは整数 -1 / 0 / +1 で持つ
- ワードは **LSB first** のタプル(`t[i]` が 3^i の桁)。不変オブジェクトとする
- 文字列表記は **MSB first**、記号は `-` / `0` / `+`(入力時は `T`、`1` も可)
- N トリット加算はキャリー入出力付きで、オーバーフロー時はラップした結果と `cout` を返す

## 理由

- LSB first にするとインデックス = 桁の重みの指数になり、リップルキャリーやゲート配線と対応がとりやすい
- 人が読む表記は通常の数字と同じく上位を左にする
- `+`/`-` はそのまま電圧の極性と対応して直感的
- ラップ + キャリー出力にしておけば、ISA 側でフラグにするか例外にするかを後から選べる(ISA の未決事項を先送りできる)
