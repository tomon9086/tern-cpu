# ADR 0001: エミュレータの実装言語に Python を使う

- 状態: **廃止**(ADR 0004 で Rust に置き換え)
- 日付: 2026-11-07

## 背景

要件定義では実装言語は「実装しながら決める」とされている。M1 の数値ライブラリを書く時点で
何かを選ぶ必要がある。

## 決定

Python 3(標準ライブラリのみ、テストは `unittest`)を使う。

## 理由

- 依存なしで動き、環境構築の手間がない
- 速度より読みやすさ・書き換えやすさが重要な段階
- テストベクタ生成・SPICE 結果との照合スクリプトにも流用しやすい
- 実機フェーズのマイコン側は MicroPython(Pico)で再利用できる可能性がある

## 見直す条件

- ゲートレベルシミュレーションの速度が問題になったとき(Rust 等への移植を検討)
