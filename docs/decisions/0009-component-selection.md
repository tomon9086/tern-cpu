# ADR 0009: 部品の選定(トランジスタ・ダイオード)

- 状態: 採用(ユーザー確認済み)
- 日付: 2026-11-13

## 決定

| 用途 | SPICE・ブレッドボード(M4, M5) | PCB 表面実装(M6〜) |
|---|---|---|
| NPN | 2N3904 | MMBT3904(SOT-23) |
| PNP | 2N3906 | MMBT3906(SOT-23) |
| ダイオード | 1N4148 | 1N4148W(SOD-123) |

## 理由

- 安価で入手しやすく、ブレッドボードに挿せる(TO-92 / DO-35)
- SPICE モデルが広く公開されており、M4 のシミュレーションと M5 の実物を同じ部品で揃えられる
- 中身が同じ表面実装版があり、将来 JLCPCB で実装してもらう場合も回路を変えずに移れる
- 耐圧 40V(トランジスタ)、100V(ダイオード)で、±5V に対し十分な余裕がある

## 設計方針: 特定の部品に依存しない

同じ型番でも hFE は数倍ばらつく。回路は特定の部品の特性に頼らず、M4 では hFE・順方向電圧・
抵抗値・温度を振った最悪条件でも 3 値を正しく判定できることを確認する。
これにより、定格の近い NPN/PNP ペア(例: SS8050 / SS8550)へも置き換えられるようにする。

置き換え可能な部品の条件(目安):

- 小信号用で、NPN と PNP が対になっている
- Vceo 20V 以上
- Ic 100mA 以上

## 要確認

- JLCPCB で Basic parts(実装の追加料金なし)に入っているか、在庫があるかは PCB 発注時に確認する
