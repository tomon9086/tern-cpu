# ADR 0006: 基本ゲートを STI / NTI / PTI / MIN / MAX にする(案 A)

- 状態: 採用(M3 着手時、ユーザー確認済み)
- 日付: 2026-11-09

## 検討した案

| 案 | 内容 |
|---|---|
| A | STI / NTI / PTI / MIN / MAX + 定数。3 値の信号を 3 値のゲートで処理する |
| B | 各トリットを 2 値 3 本に展開し、内部は 2 進論理、出口で 3 値に戻す |
| C | 抵抗で電圧を足し(7 段階)、コンパレータでキャリーと和を取り出すアナログ方式 |

## 決定

A を採用する。

## 理由

- 3 値の信号を 3 値のゲートで処理するのは A だけ(B は中身が 2 進、C は 7 値のアナログ)
- MIN / MAX はダイオードと抵抗だけで作れ、要件定義のダイオード+トランジスタ方式と合う
- 0V を能動的に作る必要があるのは STI だけで、0V 問題の検証(M4)を 1 種類の回路に絞れる
- A の中でも SUM などの作り方は複数ありうるので、M3 で数字を出して比べられる

## 評価の方針

石数だけを最小化しない。優先順は、ノイズマージン(M4)、部品総数、原因の追いやすさ、
3 進らしさ(2 値信号線の割合)。同じ素子・同じコストモデルで 2 進加算器も組み、比較の基準にする。

## 参考: Setun の素子

Setun はフェライトコアとダイオードによる電流パルス方式で、1 トリットをコア 2 個で表していた
(二次資料)。0 を「電流が流れないこと」で表し、クロックに合わせて値を読むため、
電圧レベル方式の 0V 安定化の問題が起きにくい。M4 で 0V が安定しない場合の代替案として残す。
