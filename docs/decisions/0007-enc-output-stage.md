# ADR 0007: 3 値の出力段 ENC を実験的な基本ゲートとして加える

- 状態: **採用**(2026-11-09、ユーザー確認済み)。回路としての成立は M4 の SPICE で検証する
- 日付: 2026-11-09

## 背景

M3 初版では、SUM の出力を MIN/MAX の木(ダイオード)で作り、レベル再生には BUF = STI∘STI
(トランジスタ 4)を使っていた。3 値を能動的に出せるのは STI だけだった。

## 決定

ENC(p, n) を追加する。2 値の信号 2 本で STI と同じ 2 スイッチを個別に制御し、+5V / -5V /
0V(どちらも OFF)を出す。p と n が同時に + になるのは短絡なので禁止とし、シミュレータで検出する。

## 理由

- 回路は STI の出力段そのもの(STI は入力から 2 本の制御信号を作って ENC に渡しているのと同じ)。
  0V を作る仕組みが STI と共通なので、M4 の検証対象が増えない
- SUM の「0 になる行」の項が不要になり、ダイオードが減る
- 出力がレベル再生済みになり、BUF が不要になる
- 3 値の配線を減らさずに済む(3 進らしさを下げない)

## 注意

- 制御信号のタイミングがずれると、一瞬だけ両方のスイッチが入る(貫通電流)可能性がある。M4 で確認する

## M3 での比較結果と採用の判断

3 進 9 トリット加算器(レベル再生あり系)で、部品 1962 → 1755(-11%)、ゲート段数 97 → 78(-20%)、
受動段数 6 → 4。3 値配線の数はほぼ変わらない(docs/gates.md 6 章)。

3 進らしさを重視する方針(ADR 0008)と両立する唯一の改善候補だったため、標準構成を
`AdderOptions::STANDARD`(ENC のみ)とする。s1 再利用(改善候補 1)は、効果が小さく
(部品 -3%)受動段数が伸びるため採用しない(比較用の構成としては残す)。
