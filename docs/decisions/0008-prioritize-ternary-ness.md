# ADR 0008: 回路の改善では 3 進らしさを重視する

- 状態: 採用(ユーザー確認済み)
- 日付: 2026-11-09

## 背景

M3 の比較で、部品数や速さを改善する案の多くは「2 進に展開したまま計算する範囲を広げる」
方向だった(改善候補 1: s1 再利用、2: キャリーを 2 値 3 本で渡す、4: 全加算器を 27 行の積和形にする)。
これらはコストを下げるが、3 値の配線を減らす。

## 決定

3 進らしさ(3 値すべてをとる配線を減らさないこと)を重視する。2 進に寄せてコストを下げる案は、
比較用に測ることはあっても標準構成には採らない。

## 評価の優先順(ADR 0006 を更新)

1. ノイズマージン(M4) — 動かなければ意味がないので最優先は変えない
2. 3 進らしさ(3 値配線の数)を下げないこと
3. 部品の総数
4. 原因の追いやすさ

## 影響

- 標準構成は ENC 版(ADR 0007)
- 2 進との差(現状 部品数 約 2.1 倍)をさらに詰めるには、デコードせずに SUM / ANY を作る
  回路(基本ゲートの見直しを含む)を探す必要がある。これは今後の研究課題とする
