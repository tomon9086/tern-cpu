# 回路検証(M4: SPICE)

基本ゲートを ngspice で回路として組み、±5V で 3 値を正しく出せるかを確かめる。

## 1. 環境

- ngspice 42(`apt-get install ngspice`)
- 評価スクリプト `spice/sim.py`(Python 3 標準ライブラリのみ。ADR 0004 の「補助スクリプトは必要時に言語を選ぶ」に従い、ngspice の起動と結果の集計に向く Python を使う)
- 部品モデル `spice/models/discrete.lib`(ADR 0009 の 2N3904 / 2N3906 / 1N4148 + 近似ツェナー)
- ゲート回路 `spice/cells/*.sub`

```bash
python3 spice/sim.py
```

### モデルについての注意

- 2N3904 / 2N3906 / 1N4148 は、LTspice などに同梱され広く流通している標準的なモデル値。メーカー公開モデルとの照合は未実施
- ツェナー DZ6V8 は降伏電圧と温度係数を合わせただけの近似。降伏点付近の曲がり方(ニー)は実物と違いうるので、M5 の実測で確認する

## 2. 評価方法

入力を -5.1〜+5.1V で掃引し、DC 特性を測る。

| 測定値 | 定義 |
|---|---|
| 出力+ / 出力0 / 出力- | 入力 -5V / 0V / +5V のときの出力(STI は反転) |
| しきい値- | 出力が +2.5V を下回る入力電圧(これより低い入力を `-` と読む) |
| しきい値+ | 出力が -2.5V を下回る入力電圧(これより高い入力を `+` と読む) |
| ノイズマージン | 出力の各レベルが、同じゲートのしきい値からどれだけ離れているか。NM+ = 出力+ − しきい値+、NM0上 = しきい値+ − 出力0、NM0下 = 出力0 − しきい値-、NM- = しきい値- − 出力- |

振る条件(すべての組み合わせ、計 9 通り)と負荷:

- 温度 0 / 25 / 70°C
- hFE ×0.5 / ×1 / ×2(部品ばらつき。ADR 0009 の「特定部品に依存しない」の確認)
- 負荷: 無負荷 / 同じゲートの入力 3 個 / MIN ゲートの入力(ダイオード + 47kΩ で +5V へ)/ MAX ゲートの入力(同 -5V へ)

最悪ノイズマージンは、出力レベルとしきい値をそれぞれ最悪の条件から取って組み合わせる(悲観的な見積もり)。

## 3. STI の 2 方式

### 3.1 回路

**抵抗分圧方式**(`cells/sti_div.sub`): トランジスタのベースを、電源と入力の間の分圧(約 1:10)で
駆動する。しきい値は分圧比で決まる。

**ツェナー方式**(`cells/sti_zener.sub`): ベースと入力の間に 6.8V ツェナーを入れる。
入力が 5 − 0.7 − 6.8 = −2.5V より下がると上側の PNP が ON、+2.5V より上がると下側の NPN が ON。

どちらも、出力を 0V に引く抵抗 R0 を持つ(分圧方式 10kΩ、ツェナー方式 3.3kΩ)。

### 3.3 読み取れること

- **抵抗分圧方式はしきい値が不安定**: 温度・hFE で 1.5V 以上動く。Vbe(温度で約 -2mV/°C)の変化が
  分圧比の逆数(約 11 倍)に拡大されるため。抵抗値 82k → 68k の変更だけでもしきい値が 1.2V 動いた
- **ツェナー方式はしきい値が ±2.5V 付近に収まる**(変動 0.26V 以内)。Vbe の変化が 1 倍でしか伝わらない
- **0V の安定性は R0 で決まる**: 0 の出力はどちらのスイッチも OFF で、R0 だけで 0V に引かれている。
  ダイオードゲートの入力をつなぐと電流が流れ込み、R0 = 10kΩ で ±0.8V、3.3kΩ で ±0.3V ずれる
- ツェナー方式は ON 時のベース電流が大きいので、R0 を小さく(0 を強く)しても ±5V を出し切れる。
  抵抗分圧方式では R0 = 1kΩ にすると出力が +2.5V までしか上がらなかった(試作時の測定)
- 同じゲート同士の接続(入力 3 個)では、どちらの方式も 0 はほとんどずれない(入力が上下対称なため)
